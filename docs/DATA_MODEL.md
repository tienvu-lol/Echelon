# Data Model — Echelon

## StudentProfile

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `id` | string (UUID) | Auto | uuid4 | Unique identifier |
| `major` | string | Yes | — | Student's major |
| `graduation_year` | integer | Yes | — | Expected graduation year |
| `skills` | string[] | No | [] | Technical and soft skills |
| `interests` | string[] | No | [] | Interest areas |
| `coursework` | string[] | No | [] | Relevant courses taken |
| `experience` | string[] | No | [] | Work/research experience descriptions |
| `bio` | string | No | null | Free-text bio |
| `profile_text` | string | No | null | Canonical text for embedding (auto-generated) |
| `created_at` | datetime | Auto | now | Creation timestamp |

**profile_text** is composed from: major, coursework, skills, experience, interests, and bio.

## Opportunity

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `id` | string (UUID) | Auto | uuid4 | Unique identifier |
| `title` | string | Yes | — | Opportunity title |
| `organization` | string | Yes | — | Sponsoring organization |
| `opportunity_type` | string | Yes | — | Type: internship, research, job, etc. |
| `description` | string | Yes | — | Full description |
| `skills` | string[] | No | [] | Required/preferred skills |
| `majors` | string[] | No | [] | Target majors |
| `class_years` | integer[] | No | [] | Eligible class years |
| `location` | string | No | null | Physical location |
| `paid` | boolean | No | null | Whether the position is paid |
| `deadline` | date | No | null | Application deadline |
| `contact_name` | string | No | null | Contact person |
| `contact_email` | string | No | null | Contact email |
| `apply_url` | string | No | null | Application URL |
| `source_url` | string | No | null | Where the listing was found |
| `source_name` | string | No | null | Name of the source |
| `search_text` | string | No | null | Concatenated searchable text |
| `embedding` | float[] | No | null | 768-dim Gemini embedding vector |
| `created_at` | datetime | Auto | now | First ingestion timestamp |
| `last_seen_at` | datetime | Auto | now | Last time seen during scraping |

**Critical**: `embedding` is generated by `gemini-embedding-2` with `output_dimensionality=768`. All opportunity embeddings and student profile embeddings MUST use the same model and dimension.

**Null policy**: If data (email, URL, deadline, etc.) is not present in the source, store null. Never hallucinate values.

## Swipe

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `id` | string (UUID) | Auto | uuid4 | Unique identifier |
| `student_id` | string | Yes | — | FK to StudentProfile |
| `opportunity_id` | string | Yes | — | FK to Opportunity |
| `direction` | "left" \| "right" | Yes | — | Swipe direction |
| `created_at` | datetime | Auto | now | Swipe timestamp |

## SavedOpportunity

| Field | Type | Required | Default | Description |
|---|---|---|---|---|

| `opportunity_id` | string | Yes | — | FK to Opportunity |
| `created_at` | datetime | Auto | now | Save timestamp |

## Databricks Storage

| Table | Catalog.Schema | Description |
|---|---|---|
| `students` | `{catalog}.{schema}` | Student profiles |
| `opportunities` | `{catalog}.{schema}` | Opportunity listings |
| `swipes` | `{catalog}.{schema}` | Swipe history |
| `saved_opportunities` | `{catalog}.{schema}` | Saved bookmarks |

All tables are Delta format in Unity Catalog. Embedding column type is `ARRAY<FLOAT>`.
